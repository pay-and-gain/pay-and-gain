## 正在打磨 · Currently building

### [ClawBoard](https://github.com/pay-and-gain/ClawBoard)

Windows 悬浮剪贴板历史与常用语面板，让复制过的内容更容易找到、整理和再次使用。

A floating clipboard history and phrase panel for Windows, with search, text transforms and quick paste.

**Python · tkinter · Win32 · C**

- 中文搜索、常用语分组、文本与图片剪贴板。
- 关注数据兼容、备份和可回退的升级。
- 通过自动回归和真实 Windows 交互验证，逐步改善使用体验。

[中文说明](https://github.com/pay-and-gain/ClawBoard#readme) · [English](https://github.com/pay-and-gain/ClawBoard/blob/main/README.en.md) · [使用教程](https://pay-and-gain.github.io/ClawBoard/) · [反馈问题](https://github.com/pay-and-gain/ClawBoard/issues)
